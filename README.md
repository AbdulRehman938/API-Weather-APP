# Weather App – API Project

This is a simple weather application that uses the OpenWeatherMap API to fetch current weather conditions for any city entered by the user.

## Features

- Responsive layout using HTML & CSS
- Fetches data using JavaScript and the Fetch API
- Handles API errors gracefully
- Parses and displays relevant data from JSON

## Instructions

1. Replace `YOUR_API_KEY_HERE` in `script.js` with your actual OpenWeatherMap API key.
2. Open `index.html` in a live server to see it in action.
